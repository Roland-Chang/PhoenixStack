# This is the primary instructions/agents file for the PhoenixStack environment

PhoenixStack is primarily a "Homelab" / learning environment with some "production" services for my personal use as well as for my friends and family. The goal of this environment is to provide a platform for learning and experimentation with various technologies, while also offering useful services for personal use.

I'd like to build out a well architected framework and system of modules for this environment, and to use that framework to build out a variety of services and applications. The framework should be secure, flexible and extensible, allowing for easy addition of new services and applications as needed.  It should adhere to best practices for security and performance, and should be designed with scalability in mind.    The framework should also include a robust set of tools and utilities for managing and monitoring the environment, as well as for automating common tasks and processes.    Overall, the goal of this environment is to provide a rich and engaging learning experience, while also offering practical and useful services for personal use.

Please use this prompt and the existing files/folders in this folder to create the Agents.md or Instructions.md file that will serve as the beginning of our project.  Please also create a README.md file for the GitHub repository.  Steps moving forward should be methodical, small (I don't want to get too far ahead of myself or be subject to unnecessary scope/feature creep), and above all, should have security at the forefront of all considerations.
